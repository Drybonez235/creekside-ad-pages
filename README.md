# Landing Pages Workspace

A centralized monorepo containing landing page projects managed via Git Subtree. Each project folder maintains its own isolated directory structure suitable for standalone repository syncs.

## Directory Structure

```text
├── company-a/          # Isolated landing page project A
├── company-b/          # Isolated landing page project B
├── canvasHomes/        # Canvas Homes landing page project
├── README.md           # Workspace documentation
├── CLAUDE.md           # Guidance for AI coding assistants
└── .gitignore          # Global git ignore policy
